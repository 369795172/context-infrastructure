# 外部写作：自审与只读验收指南

> [!NOTE]
> **适用阶段**：供 **IC-3** 最终写作角色及 **Manager** 在只读验收阶段阅读使用。
> 本文件所涉及的权限边界与交付合同，始终以 [外部写作与成文工作流](./workflow_external_writing.md) 的第 0 节为准。本指南仅提供具体的阶段性执行细节，不授予 Manager 任何对最终正文的修改权限。

## IC-3 输入与输出要求

IC-3 必须启动全新的 Antigravity 会话来运行。它需要完整读取设计简报、素材包、重写稿、口吻校准集、沟通风格指南、微观文风手册以及冻结后的图片契约。其产出物包括：

- `article_final_vN.md`：完整、可独立交付的候选文本，禁止只提供局部补丁。
- `prose_qa_vN.md`：包含审查证据和各项门控结果的自审报告。

IC-3 是最终文本的唯一权威。它拥有充分的裁量权来拆分句子、合并段落、调整词汇或从空白页重写全文，但绝对不能改变设计简报中约定的核心论点、核心主张、事实归因、数字、链接、二级标题依赖关系以及图片契约。

## IC-3 十大审查维度

在生成候选文本时，IC-3 必须对照以下十个维度进行深度审查：

1. **整篇声线控制**：检查开头、各个二级标题的入口以及结尾是否仍带有明显的教材腔。如果正文中出现三处以上“宣布主题、依次定义对象、最后抽象总结”的结构，必须从空白页重写整篇 prose，不能只修相关章节。
2. **零背景阅读友好**：确保公司名称、论文、法规、产品、关键事件和技术术语在首次出现时就具备充足的解释或上下文，不依赖读者的隐藏背景。
3. **消除翻译腔**：剔除直译产生的抽象主语、硬译动词、无信息增量的双语括注、中英文无空格混排以及机械的过渡词。
4. **提升认知舒适度**：通过冷读测试、检查工作记忆负担、首段复述效果、场景的连续性以及局部地图的设计，确保读者阅读时不产生困惑。
5. **剔除模板与脚手架**：彻底清除人工智能常见的高频对照模板、自我评价性的标签词，以及设计简报、公理库、阶段划分等内部分析框架的泄漏。
6. **局部连贯性**：确保相邻句子和段落之间有自然的因果或逻辑过渡，代词指代对象清晰明确，标题能够精准概括其下属正文。
7. **避免无谓重复**：检查事实、判断、过渡词和特定句式在近距离内是否存在高频重复。
8. **与校准集对照**：确保文章相比于优秀的成稿样本，不会显得更像一份说明书、新闻通稿或课堂讲义。
9. **防止过度口语化**：剔除所有装饰性的比喻、网络流行语、拟人化修辞、俚语以及没有任何证据支持的绝对化判断。
10. **上下文连续性**：不要在正文中去回答读者没有提出来的问题。删除章节时，必须同步清理没有兑现的铺垫、交叉引用或孤立的配图。

## 两项核心读者门控

- **理解门控（Comprehension Gate）**：零背景的普通读者在不查阅外部资料的情况下，能够完全读懂正文中的每一个概念，并能准确叙述出文章的核心论点。
- **认知舒适度门控（Cognitive Comfort Gate）**：读者在阅读过程中不需要频繁停顿、往回重读，也不需要同时在脑海中维护多条尚未落地的抽象关系。

自审报告 `prose_qa_vN.md` 必须对整篇声线的判定、十个维度的排查过程、主要修改的位置、至少四组修改前后的句子对比、标题冷读与首段复述的结果、保留未改动的数字、URL 和图片数量、两项门控的具体结论、确定性扫描结果以及是否存在阻塞性问题进行逐项真实记录。

## IC-3 的权限边界

如果 IC-3 发现文章存在某些问题，而这些问题需要通过增加新事实、修改核心论点、增删主要主张、重排主要章节或调整证据链才能解决，IC-3 绝对不能擅自处理。此时，必须保持对应内容不动，并在自审报告中标记阻塞（BLOCKER），明确指出具体的位置、依赖的缺口，以及需要回溯到哪一个上游工件。

## Manager 只读验收协议

Manager 需要完整读取 IC-3 提交的候选文本、自审报告、设计简报以及素材包，执行新主张审计（New-claim audit），在此期间不能对候选文本做任何字符层面的修改。Manager 应当重点验证：

- 每一项事实、数字、归因、链接和专有名词在素材包中是否均有据可查。
- 文章中主张的强度是否超越了素材包中的证据边界。
- 标题、二级标题的顺序、图片路径和引用位置是否与简报一致。
- IC-3 是否在重写时误删了约束条件、引入了简报之外的新事实，或改变了既定结论。
- 两项核心读者门控以及统一 Go/No-go 门控是否真实通过。

若发现任何问题，Manager 必须编写只读审计报告 `content_audit_vN.md`。审计报告中必须列出候选文本的原句或位置、对应的证据边界、失败的门控、带来的理解风险，以及允许的修改方向。**审计报告中绝对不能包含 Manager 替 Agent 写好的修改后段落。**

编写完审计报告后，Manager 必须启动全新的 Antigravity 会话。新会话读取权威的设计简报、素材包、上一版完整候选文本、最新的审计报告以及文风校准文件，从空白页开始输出完整的新版候选文本与自审报告。禁止让 Manager 拼接不同的版本。

## 收敛与停止条件

每个任务最多只允许进行三轮 IC-3 候选文本的迭代。在这三轮中，一旦有某一版候选文本通过了全部门控，必须立即停止生成并进入交付阶段。如果执行到第三轮依然存在阻塞性问题，必须立即停止，保留全部的中间工件并向用户报告具体失败原因，严禁强行将未通过门控的候选文本标记为最终版本。
